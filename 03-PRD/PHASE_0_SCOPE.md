## Phase 0 Boundaries

### What Phase 0 DOES

- Documents governance principles
- Documents user roles and responsibilities
- Documents the existing justice ecosystem (architecture only)
- Documents the scope boundary
- Documents risks and mitigations
- Establishes the legal-source governance framework (principles only)
- Establishes the security baseline (principles only)
- Records all significant decisions

### What Phase 0 DOES NOT DO

- Does not write application source code
- Does not install npm packages or dependencies
- Does not create database schemas or migrations
- Does not create API endpoints
- Does not create React/frontend components
- Does not create backend services
- Does not create fake legal data
- Does not create fake government APIs
- Does not create fake lawyer profiles
- Does not create unofficial government integrations
- Does not invent legal rules or legal conclusions
- Does not claim government partnerships or endorsements
- Does not use real citizen personal data

---

## Transition to Phase 1

Phase 1 (PRD & Acceptance Criteria) begins only on explicit user instruction.

Phase 1 will:
- Freeze requirements
- Define roles formally
- Write user stories
- Define non-functional requirements
- Create a requirements traceability matrix

Phase 1 will NOT begin automatically.
